# @firstflip/agents

Zero-dependency tools for AI coding agents and shell-first developers to call the FirstFlip
Business API. Generated from the published contract (`openapi.yaml` + `api/services.openapi.json`).

## What is in here

- `tools.json` — the 53 API-key operations in agent-friendly shape: name, description, JSON
  Schema input, scope, method, path. Generated by `scripts/build-agent-tools.js` from the
  contract; never hand-maintained.
- `mcp-server.js` — a stdio MCP server (JSON-RPC 2.0, newline-delimited). Spawn it, send
  `initialize`, then `tools/list` and `tools/call`. Key from `FIRSTFLIP_SECRET_KEY`.
- `firstflip-cli.js` — a CLI: `firstflip list`, `firstflip describe <op>`, `firstflip call <op>
  --body '{…}'`. Same key, same contract.
- `lib.js` — the shared request builder/executor. Zero dependencies; Node 18+.

## Install

```bash
npm install @firstflip/agents
```

The release package includes the portable `skills/firstflip-integration` directory with the public
contracts and guide bundle. Copy that complete directory to your agent's supported skill location.
Publishing to npm and the MCP Registry are separate release steps; a checked source tree alone is
not proof that either listing exists.

## Use the MCP server

```json
{
  "mcpServers": {
    "firstflip": {
      "command": "npx",
      "args": ["--yes", "@firstflip/agents@0.1.0-beta.2"],
      "env": { "FIRSTFLIP_SECRET_KEY": "ffk_test_…" }
    }
  }
}
```

## Use the CLI

```bash
export FIRSTFLIP_SECRET_KEY=ffk_test_…
npx --package @firstflip/agents@0.1.0-beta.2 firstflip list
npx --package @firstflip/agents@0.1.0-beta.2 firstflip call createCharge --body '{"amount":25000,"currency":"NGN"}' --idempotency-key purchase-42
```

## Tests

```bash
node --test test/*.test.js
```

MCP writes require an explicit `idempotency_key`; choose it before the operation and reuse it with
identical arguments after a timeout. The CLI generates one when omitted and prints it to stderr.
Test keys simulate supported operations. Live keys remain subject to API eligibility, scopes and
per-service gates. The MCP server describes the configured mode and marks writes conservatively.

The suite proves the catalog has 53 tools, every schema is clean JSON Schema (no `$ref`, no
`x-` keys, no OpenAPI-only keywords), the MCP server answers `initialize` / `tools/list` /
`tools/call` correctly, the CLI exits 0/1/2 by kind, and the real stdio loop round-trips
over a spawned process.
